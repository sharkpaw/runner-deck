# Shared apt package list for the Manager and Runner images.
#
# Both images run GitHub Actions jobs (the Manager in default mode, the Runner in container mode),
# so their dependencies must match. Previously each Dockerfile kept its own package list. v1.1.0 added
# git/build-essential/gnupg only to the Runner image and not to the Manager image, so jobs in default mode failed with
# "git: command not found". With a single list, the dependencies can no longer drift in one direction.
#
# === Baseline: matches the apt base layer of GitHub-hosted runners ===
#
# Source: apt.vital_packages + apt.common_packages + apt.cmd_packages (74 items total) in
#       images/ubuntu/toolsets/toolset-2404.json of the actions/runner-images repo.
# Purpose: workflows written for runs-on: ubuntu-24.04 should not fail on self-hosted runners for lack of base commands.
#
# Language and platform SDKs (Node, Python, Android, etc.) are not included. They account for the hosted image's 40GB size,
# and their versions vary by project, so workflows should install them with setup-* actions, or extend the image
# for the project as shown in examples/runner-images/.
#
# The only noble-specific fixes:
#   netcat -> netcat-openbsd
#     netcat is a virtual package on 24.04, provided by both netcat-openbsd and netcat-traditional,
#     and apt cannot choose between them automatically, so the choice must be stated explicitly.
#   (upx, libssl3, and liblttng-ust1 are also virtual packages, but each has only one provider, so apt resolves them; kept as-is)
#
# Intentionally excluded (does not work in a container, or may not be installable from default sources):
#   pollinate         Ubuntu cloud instance entropy seed service; meaningless in a container and makes outbound calls
#   systemd-coredump  no systemd inside containers
#   haveged           entropy daemon; not needed on modern kernels
#   ssh               openssh-server comes in with the metapackage; sshd does not run in the container, only openssh-client is kept
#   p7zip-rar         multiverse component, may not be enabled in the base image; p7zip-full covers common cases
#
# Extra packages (not in the three apt lists above, but hosted images have them too):
#   git               runner-images installs a specific version from a PPA with a separate script, not via the apt list;
#                     without it actions/checkout silently falls back to a tar extract with no .git directory
#   build-essential   pulls in libc6-dev and similar; hosted images get them indirectly through the -dev packages
#
# All package names were verified as a whole on ubuntu:24.04 with apt-get install --simulate: they resolve and have no conflicts.
# One package per line; lines starting with # and blank lines are ignored.
